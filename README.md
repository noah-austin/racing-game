# Racing Game

A first-person browser racing game built around race craft rather than raw car control:
forgiving handling, mistakes that cost tenths instead of the race.

## Run

```
npm install
npm run dev
```

Controls: W/↑ throttle, S/↓/Space brake (hold when stopped to reverse), A D/← → steer,
R reset to track, M mute. Gamepad: left stick and triggers.
Touch (landscape): drag on the left half to steer, pedal buttons on the right.

Add `?auto` to the URL to watch the autopilot drive.
